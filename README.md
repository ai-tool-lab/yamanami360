# ⛰️ 山並み360°｜淵野辺

JR淵野辺駅（相模原市）から見える **丹沢山系** と **秩父・奥秩父山系** の山並みを、3Dパノラマで見渡せるWebアプリです。山名ラベルをクリックすると、標高・距離・方位・見通し仰角・登山ルート・山小屋情報を表示します。

## 主な機能

- **360°パノラマビュー** — 淵野辺駅（標高121m＋目線1.6m）からの眺めを Three.js で描画。地球の丸みと大気差による見え方の補正込み
- **山名ラベル** — 山頂ピーク（青）と峠・スポット（オレンジ）を表示。ラベル同士が重ならないよう自動で高さを調整
- **詳細パネル** — 標高、淵野辺駅からの直線距離、方位角（16方位）、見通し仰角、山の概要、登山ルート、山小屋、国土地理院地図・Wikipedia へのリンク
- **視点プリセット** — 丹沢山系全景 / 秩父山系全景 / 大山周辺 / 塔ノ岳・鍋割山 / 奥秩父主脈（甲武信・雲取）
- **表示切り替え** — 山頂ピーク・峠スポットそれぞれ ON/OFF
- **方位コンパス＆広域ミニマップ（半径80km）**

## 操作方法

| 操作 | 動作 |
|---|---|
| ドラッグ | 見回し（方位・仰角） |
| マウスホイール | ズーム |
| ラベルをクリック | 詳細パネルを表示 |

## 起動方法

ビルドは不要です。`index.html` 1ファイルで動作します（Three.js を CDN から読み込むため、インターネット接続が必要です）。

ローカルで確認する場合は、静的サーバーで配信してブラウザで開いてください。

```bash
npx serve .
```

または

```bash
python -m http.server 8000
```

## 収録地点

- **丹沢山系** — 大山、表尾根（二ノ塔・三ノ塔・烏尾山・行者岳・新大日 ほか）、塔ノ岳、鍋割山稜、ヤビツ峠、大倉 など
- **秩父・奥秩父山系** — 雲取山、武甲山、甲武信ヶ岳、三宝山、雁坂嶺、和名倉山、両神山、御座山、秩父盆地 など

## 注意

地形は実測の標高データ（DEM）ではなく、各山頂の位置と標高から作った近似の形です。山頂の位置・方位・仰角は計算値ですが、稜線の形は実際とは異なります。
